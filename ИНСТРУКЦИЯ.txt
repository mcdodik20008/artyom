ЧТО ЗДЕСЬ ЕСТЬ?
--------------
Полная коллекция примеров задач из ЕГЭ по информатике с решениями на Python.
Все задачи организованы по темам и готовы к запуску!


БЫСТРЫЙ СТАРТ:
--------------
1. Запусти файл:
   python quick_start.py

   Этот файл покажет тебе примеры основных типов задач.

2. Изучи шпаргалку:
   Открой файл: ege_tasks\CHEATSHEET.md
   Там есть все основные команды Python для ЕГЭ!


СТРУКТУРА ПАПКИ ege_tasks:
--------------------------
task_05_systems\        - Задачи на системы счисления
  example_01.py         - Простой пример
  example_02.py         - Сложнее

task_16_recursion\      - Задачи на рекурсию
  example_01.py         - Простая рекурсия
  example_02_advanced.py - Взаимная рекурсия

task_17_sequences\      - Задачи на последовательности
  example_01.py         - Поиск пар в последовательности
  example_02_with_file.py - Работа с файлами

task_25_divisors\       - Задачи на делители чисел
  example_01.py         - Поиск чисел с N делителями
  example_02.py         - Нечётные делители

task_08_combinatorics\  - Задачи на комбинаторику
  example_01.py         - Перестановки без повторений
  example_02.py         - С повторениями

practice\               - Практические упражнения
  exercises.py          - 5 задач для самостоятельного решения
  template.py           - Шаблон для своих решений


КАК УЧИТЬСЯ:
------------
СПОСОБ 1 - Пошаговое изучение:
   1. Открой файл задачи в редакторе (например, task_05_systems\example_01.py)
   2. Прочитай условие в начале файла
   3. Попробуй понять, как работает решение
   4. Запусти: python ege_tasks\task_05_systems\example_01.py
   5. Экспериментируй: меняй числа, условия
   6. Переходи к следующей задаче

СПОСОБ 2 - Практика:
   1. Открой practice\exercises.py
   2. Читай условие задачи
   3. Попробуй решить сам
   4. Проверь ответ (он в конце файла)

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ:
------------------------
1. Проблема с кодировкой в консоли (русские буквы - квадратики):
   - Это нормально для Windows консоли
   - Главное, что программа РАБОТАЕТ и выдаёт правильные числа!
   - Можно открывать файлы в редакторе и читать там

2. Ошибка "python не найден":
   - Убедись, что Python установлен
   - Попробуй: python3 вместо python

3. Другие ошибки:
   - Убедись, что ты в правильной папке (D:\projPython\artyom)
   - Используй команду: cd D:\projPython\artyom

СОВЕТЫ ДЛЯ УСПЕШНОЙ ПОДГОТОВКИ:
-------------------------------
1. Решай задачи каждый день (хотя бы 15-30 минут)

4. Экспериментируй: меняй условия, числа, проверяй гипотезы
