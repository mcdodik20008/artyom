  def count_divisors(n):
      count = 0
      i = 1
      while i * i <= n:
          if n % i == 0:
              count += 1
              if i != n // i: count += 1
          i += 1
      return count

Динамика (задача 23):

  dp[start] = 1

      dp[i*2] += dp[i]
